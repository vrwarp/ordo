# Review: the ProPresenter 7 importer against real files (2026-11-05)

Until this review every ProPresenter test fed the importer documents we had encoded ourselves with the
same community schema the importer reads, so the tests proved the reader against our own writing. This
review ran the importer over files ProPresenter itself exported, found in two MIT-licensed projects
(propresenter7-php-lib's reference samples and Pro7ChordEditor's test data: 16 `.pro`, 3 `.proplaylist`,
2 `.probundle`), compared its output with those projects' own expected results, scanned the raw protobuf
wire format for fields the vendored schema does not know, and had two independent reviewers read the
importer and the hub's import job against the files. Four of the files are now in the repository
(`packages/importers/test-fixtures/pro7/`, see its NOTICE) and `pro7.real.test.ts` checks them.

## Noted, not changed

- **Leading and trailing blank lines are still trimmed.** In ProPresenter an empty paragraph takes a
  line, so a middle-aligned box positioned with blank lines sits slightly higher in ordo. Deliberate:
  lyrics are tidied for projection.
- **Per-side margins become one padding** (the largest), logged.
- **Slide labels, hot keys and group colours** are logged, not kept; the domain has no fields for them.
- **The vendored schema is the ProPresenter 7.x community set.** On these files it misses only a
  ligature style, an image alpha-type flag and two bookkeeping fields. The 21.4 autogenerated set in the
  same repository is the one to move to when a file shows fields that matter.
- **No Windows-written file was available.** Every sample is from a Mac; the Windows RTF dialect is
  unverified.
- **Only four small real files are in the repository.** The remaining samples (and your own library
  export) are the real test; the capture scripts are in the session scratchpad, not the repository.

## Verification

Lint, typecheck, the full unit suites and the new real-file tests pass. The ProPresenter-written bundle,
the playlist export and the 7.9 song were also pushed through the running hub: the background arrives
as a background media item, the playlist items carry their arrangements, and re-importing updates the
earlier copies.
