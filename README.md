# ordo

A browser-native live presentation system for venues: lyrics, slides, media, lower
thirds and a stage display, run entirely in Google Chrome from a URL, with a small hub
service on the venue LAN. Zero install on the presentation computer, zero dropped frames
on the audience screens.

Status: design complete for the first prototype, implementation not started.
